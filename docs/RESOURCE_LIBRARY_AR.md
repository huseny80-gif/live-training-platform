# مكتبة الموارد الرقمية

المسار `/resources` محمي بحساب المدرب. يعرض موارد جميع البرامج التي يملكها المدرب، ويمكن تصفية برنامج محدد أو البحث عبر الأقسام بعناوين الموارد وأسماء البرامج. توجد روابط في شريط المنصة ولوحة المدرب.

الأقسام الافتراضية: المادة الامتحانية، الفيديوهات، الشرائح، وثائق Word، نتائج الاختبارات، والواجبات. تظهر المحاضرات والمواد الامتحانية وتفريغات الفيديو وجلسات النتائج من سجلاتها الأصلية، دون نسخ تلك السجلات أو تأليف أسماء ملفات أو أحجام. المواد الامتحانية تُنزّل JSON خاصًا بالمدرب، والتفريغات SRT، والنتائج Excel من التصدير الحالي. إدارة الموارد المرتبطة تتم من صفحاتها الأصلية.

إضافة الملفات والأقسام المخصصة محفوظة في `ResourceFile` و`ResourceCategory` عبر الترحيل `20261012170000_resource_library`. الملفات المقبولة PDF، DOCX، PPTX، XLSX، TXT حتى ٣٠ MB، وMP4 وWebM حتى ٥١٢ MB. لكل برنامج حد ١٠٠٠ سجل مورد و٢٠ محاولة إضافة خلال ١٥ دقيقة. الملفات في المكتبة ليست مصادر توليد تلقائية؛ يُختار المصدر ويُراجع في مسار المادة الامتحانية.

في الإنتاج يستعمل المتصفح Vercel Blob الموجود لرفع الملفات مباشرة، مع رفع متعدد الأجزاء للفيديو الكبير. يحجز الخادم معرفًا ومسارًا عشوائيًا محدودًا بالبرنامج، ويفوض MIME والحجم والمسار المحدد فقط بعد التحقق من الملكية. يتحقق إكمال الرفع من التخزين الخاص وبيانات `head` داخل المتجر المضبوط، ولا يجلب URL من مضيف يحدده المستخدم. التسجيل صالح ساعة، والإكمال متكرر بأمان. يعمل إشعار Blob والتسجيل من المتصفح معًا. عند التطوير دون Blob يستعمل المسار المحلي المحمي والتخزين خارج `public/`.

لا يستطيع حساب آخر تحميل الموارد أو تعديلها. التحميل من Blob يصدر URL قراءة خاصًا بالمورد فقط، صالحًا لعشر دقائق للملفات ولساعتين للفيديو، بعد فحص الحساب وحالة المورد. لا يُرسل مفتاح المتجر إلى المتصفح. هذه الروابط المؤقتة تصبح غير قابلة للاستخدام بعد انتهاء مدتها؛ حذف المورد يمنع إصدار رابط جديد، لكنه لا يلغي رابطًا مؤقتًا صدر مسبقًا قبل انتهاء مدته. تُضبط الاستجابات الخاصة على `private, no-store`.

المعاينة: PDF عبر المتصفح، الفيديو عبر مشغل الفيديو، وDOCX/PPTX/XLSX/TXT كنص. لا تمثل المعاينة النصية تنسيق Office الأصلي؛ يعرض Excel أول ١٠٠ صف من أول عشر أوراق، والنص حتى ٥٠ ألف حرف. حد المعاينة المكتبية ١٠ MB مضغوطًا وبعد التوسيع، ويُرفض التوسع الكبير قبل فك الضغط. يظل تحميل الملف الأصلي متاحًا إذا تعذرت المعاينة. تُعرض النصوص كنص React دون تنفيذ HTML أو الصيغ.

يمكن تعديل عنوان ملف المكتبة ونقله إلى المحذوفات واستعادته؛ يبقى الملف الأصلي محفوظًا. الأقسام الجديدة تخص البرنامج المحدد وتظهر معه ضمن العرض الشامل. لا تُنشأ بيانات مثال في الإنتاج ولا تُنشر الموارد للطلاب تلقائيًا.

التحقق:

```sh
npx tsx tests/resources-service.test.ts
npx tsx tests/resource-directory.test.ts
npx tsx tests/resource-preview.test.ts
npx tsx tests/resources-download.test.ts
npx tsx tests/resources-ui.test.ts
npm run build
```

تختبر المعاينة أرشيفات Office حقيقية مولدة للاختبار. اختبارات قاعدة البيانات وBlob تستخدم بدائل، واختبار المتصفح يشغل المكونات الفعلية ورفع الملف إلى API اختبارية على الهاتف والحاسوب. الإنتاج يعتمد على `DATABASE_URL` و`BLOB_READ_WRITE_TOKEN` المضبوطين حاليًا؛ يطبق مسار النشر الترحيل قبل نشر التطبيق.

نجح فحص التخزين الفعلي في الإنتاج بتاريخ ١٢ أكتوبر ٢٠٢٦: إصدار URL قراءة خاص ومحدد بملف PDF موجود، وقراءة جزء منه عبر HTTP 206. لم يُنشأ مورد اختباري ولم تُكتب سجلات تدريب. أُوقف الفحص التلقائي بعد النجاح؛ يبقى تقريره التاريخي ضمن إيصال الصيانة، ويمكن تشغيل السكربت يدويًا عند التشخيص المصرّح به.
